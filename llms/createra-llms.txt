# Createra

> Createra is a user-generated-content (UGC) gaming metaverse platform backed by
> Andreessen Horowitz, built by the Code Infinity team associated with the
> youth-coding company Codemao. Creators build and publish 3D worlds and games in
> the browser via its Box3 creation platform. As of a 2026-07-20 probe the company
> has no reachable website and no public API surface; this file records what the
> API Evangelist network was able to verify.

## Status

- Company status: dormant. createra.fun resolves in DNS (A 152.69.222.7) but no
  service answers on port 80 or 443.
- No developer portal, documentation, API reference, OpenAPI/AsyncAPI definition,
  MCP server, or /.well-known discovery surface could be located.
- No vulnerability-disclosure program, trust center, status page, or changelog
  could be located.

## Packages
